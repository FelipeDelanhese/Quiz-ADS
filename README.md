# Quiz ADS - Estuda Comigo 🎓

Um quiz interativo para revisar os principais temas do primeiro semestre de Análise e Desenvolvimento de Sistemas (ADS).

## O que tem no quiz

- **5 temas**: Lógica de Programação, Algoritmos e Fluxogramas, Python - Fundamentos, Fundamentos de TI e Matemática para Computação
- Mais de 40 perguntas de múltipla escolha
- Seleção de temas e quantidade de perguntas
- Modo desafio opcional com cronômetro
- Explicação de cada resposta, certa ou errada
- Tela final com revisão completa das perguntas erradas

## Como rodar localmente

É um único arquivo HTML, sem dependências. Basta abrir o `index.html` em qualquer navegador.

## Como está publicado

Este projeto está publicado via GitHub Pages. Veja o link em "About" deste repositório.
